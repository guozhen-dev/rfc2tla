# Artifact Status

The package supports offline replay of recorded construction-tool actions and local TLC verification. The source, 22 tool schemas, TLC JAR, fixed real and synthetic inputs, and core TLA+/TLC replay traces are included. See `README.md` for the tested core replay commands.

This artifact demonstrates that RFC2TLA+ can reliably build TLA+ models from recorded LLM construction actions and check them with TLC. We therefore apply for the Functional and Available badges.
